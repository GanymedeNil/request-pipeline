Pipe a tab's network traffic into your own code.

Request Pipeline forwards each request a tab makes, with headers, bodies, cookies and timing, to a server you run, as JSON, while you browse. No proxy, and no DevTools left open.

From tab to code in three steps

The receiver can be anything that accepts a JSON POST. One is included to get you started.

  1. Run a receiver

    The repository includes one. It needs Python 3 and nothing else:

    python3 examples/receiver.py

    It prints each request, and can save JSONL or a HAR file that opens in Chrome DevTools.

  2. Start capture

    Open the page, click the extension icon and press Start capture. Turn on Reload the page to catch the requests it makes while loading.

    Chrome shows a banner while a tab is being captured. Press Stop capture to end it.

  3. Use the records

    Each finished request arrives as one JSON POST. Feed it to tests, mocks, scrapers or your own debugging tools.

One request, one record

Field names follow the Chrome DevTools Protocol, so they match what you see in DevTools. Full format

request
Method, URL, headers and the complete body, even when it's large.
response
Status, headers and MIME type.
response_body
The body as text, or base64 for binary.
cookies
The cookies Chrome holds for the request's URL.
timestamp
When it was sent, plus duration_ms for how long it took.
schema_version
So your code can rely on the shape.
{
  "schema_version": 1,
  "resource_type": "Fetch",
  "timestamp": 1794795192008,
  "duration_ms": 120,
  "request": {
    "method": "POST",
    "url": "https://shop.example/api/orders/1042/notes",
    "headers": {
      "Authorization": "[REDACTED]",
      "Content-Type": "application/json" …
    },
    "postData": "{\"note\":\"Gift wrap, please\"}"
  },
  "response": {
    "status": 201,
    "mimeType": "application/json" …
  },
  "cookies": [
    { "name": "session", "value": "[REDACTED]" … }
  ],
  "response_body": {
    "body": "{\"id\":\"n_88\",\"created\":true}",
    "base64Encoded": false
  }
}

Decide what leaves the browser

Everything is in the popup, and changes apply to the next request, even mid-capture.

  • Filter by resource type, URL pattern and HTTP method.
  • Redact cookie values and authorization headers before they're sent.
  • Trim bodies over a size limit to a marker that keeps their length.
  • See what happened in live counts, and get a clear error when your server is down.

Your traffic goes to your server. Nowhere else.

Records go only to the address you set, which is your own computer by default (127.0.0.1:6789). The extension has no analytics and sends nothing to us.
