Privacy policy

Effective November 16, 2026

The Request Pipeline extension sends the network traffic you capture only to the server address you set, which is your own computer unless you change it. Nothing goes to the developer, and nothing is used for advertising or analytics, or sold.

This policy covers the Request Pipeline Chrome extension and this website. Request Pipeline is open-source software; you can check every statement below against its source code.

What the extension reads

  • The network traffic of the tab you choose, only while a capture you started is running: request URLs, methods, headers and bodies; response status, headers and bodies; the cookies Chrome holds for each request's URL; timing; the tab's ID; and the address of the page that made each request. In versions that offer it, and only if you turn it on, it also reads WebSocket and EventSource messages.
  • The titles and addresses of your open tabs, to list them in the popup so you can choose one. They stay in the popup and are not sent anywhere.

Depending on the pages you capture, this traffic can contain personal information, such as names, email addresses or messages shown on those pages, and credentials such as session cookies and authorization headers.

Where it goes

  • Each captured request is sent as an HTTP POST to the server address set in the popup, and nowhere else. The default is http://127.0.0.1:6789, which is your own computer. If you enter another address, records go to that server, and whoever runs it is responsible for them.
  • Nothing is sent to the developer of Request Pipeline or to any other third party. The extension has no analytics, telemetry, crash reporting or advertising, and it doesn't load remote code.
  • Redact credentials in the popup's Options replaces the values of Authorization, Cookie, Set-Cookie and similar headers, and of all cookies, with [REDACTED] before anything is sent. URLs and bodies are sent as they are.
  • For a server that isn't on your computer, use an https:// address. The popup warns you when the address isn't local or isn't encrypted.

What it stores on your computer

  • Your settings (server address, filters and options), in Chrome's storage for extensions.
  • The state of the current capture (which tab, the forwarded, failed and skipped counts, and the last forwarding error), in Chrome's session storage, which is cleared when Chrome closes.
  • Whether you left the Options section open, in the popup's local storage.

Captured requests are kept in memory only until they are sent; the extension doesn't save them. Removing the extension deletes everything it stored.

Permissions

Permission Why the extension needs it
debugger To read the network traffic of the tab you choose, only after you press Start capture.
tabs To list your open tabs in the popup so you can choose one.
storage To remember your settings and the state of a running capture.
Access to websites To send records to the server address you configure, whatever its address.

Chrome Web Store user data policy

The use of information the extension handles adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements. The data is used only to forward it to the server you configure, which is the extension's single purpose. It isn't sold, isn't used to determine creditworthiness or for lending, and isn't transferred to anyone else.

This website

This site sets no cookies, has no analytics and loads nothing from other sites; even its fonts are served from here. It is hosted on GitHub Pages, and GitHub may log visitors' IP addresses for security purposes, as described in the GitHub General Privacy Statement. Links to GitHub and the Chrome Web Store take you to services with their own privacy policies; the extension's Feedback link opens GitHub.

Children

Request Pipeline is a developer tool and isn't directed at children under 13.

Changes

Changes to this policy are published on this page with a new effective date. Earlier versions are in the repository's history.
